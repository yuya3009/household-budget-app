# 家計簿アプリ 詳細設計書

## 第22章 SCR-008 支出削減設定画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-010

支出削減の設定は2画面で行う。本画面で**どのカテゴリを、どの順番で削減するか**を決め、次の[SCR-009 削減金額設定](23_詳細設計書_SCR-009削減金額設定.md)で**いくら削減するか**を決めて保存する。

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `HintCard` | 使い方の説明。ページ上部に「**削減対象は3つまで選べます**」と表示する |
| ② | `ToggleSwitch`（ListItem内） | 削減対象／維持対象の切替 |
| ③ | `PrioritySelect`（ListItem内のプルダウン） | 削減優先度（1が最優先）。選択肢は 1〜3 |
| ④ | `PrimaryButton`「次へ」 | 押下で SCR-009 へ遷移。削減対象が0件の場合はエラー |
| — | `ListItem`（SCR-008用）, `AppBar`（戻るあり）, `Toast`, `AppFooter` | 各行に前月の支出額を併記 |

### 2. バリエーション

#### 2-1. 行の状態

| 切替要素 | 削減（ON） | 維持（OFF） |
|---|---|---|
| タグ | 「削減」（塗り） | 「維持」 |
| 優先度プルダウン | 操作可能（**1〜3**） | 非活性（「-」表示、薄く表示） |
| SCR-009への引き継ぎ | 対象になる | 対象外 |

#### 2-2. ④「次へ」ボタンとバリデーション

| 削減対象（ONの行）の件数 | 「次へ」押下時 |
|---|---|
| 1件以上 | 選択内容（カテゴリ・優先度）を画面側で保持して SCR-009 へ遷移。**この時点ではDBに保存しない** |
| 0件 | エラー「**削減対象は1個以上選択してください**」を表示し、SCR-009 へは遷移しない |

#### 2-3. 優先度プルダウン

- 優先度は **1〜3 のみ**表示・選択できる（0 と 4 以上は選択肢に出さない）。
- 選択肢に出すのは **1〜削減対象の件数**まで。

  | 削減対象（ONの件数） | 選択肢 |
  |---|---|
  | 1件 | 1 |
  | 2件 | 1、2 |
  | 3件 | 1、2、3 |

- 優先度の重複・欠番は起きないように、次のルールで自動調整する（エラーは出さない）。

  | 操作 | 動き | 例（外食1・娯楽2・衣服3） |
  |---|---|---|
  | プルダウンで優先度を変更 | 選んだ数字を持っていたカテゴリと**入れ替える** | 衣服で「1」を選ぶ → 衣服1・娯楽2・外食3 |
  | スイッチをON | 優先度に「今の件数＋1」を自動で設定 | 外食1のみの状態で娯楽をON → 娯楽2 |
  | スイッチをOFF | その行の優先度を破棄し、残りを1から**詰め直す** | 娯楽をOFF → 外食1・衣服2 |

#### 2-4. 削減対象の上限（3件）

| ONの件数 | ONの行のスイッチ | OFFの行のスイッチ |
|---|---|---|
| 0〜2件 | 操作可能 | 操作可能 |
| **3件** | 操作可能（OFFにできる） | **非活性**（灰色で押せない） |

- 3件のときは、OFFの行の**優先度プルダウンも非活性**で選択できない（OFFの行の優先度は常に非活性）。
- 3件のうちどれかをOFFにすると、OFFの行のスイッチは再び操作できるようになる。
- 上限は優先度の範囲（1〜3）と同じ3件。

### 3. 注意点

- 対象は**支出用カテゴリ（category_type=01）のみ**。デフォルトカテゴリと自分が作成したカテゴリを表示し、収入用は表示しない。
- カテゴリの追加・編集・削除はできない（SCR-006で行う）。SCR-006 で削除されたカテゴリは、この画面に表示しない（削減対象だった場合の優先度は、削除時に自動で詰め直されている）。
- 初期表示は保存済みの設定（category_classification）。削減対象の行を優先度順に先に並べ、その下に維持対象の行を並べる。
- 優先度は `reduction_number`（SMALLINT）。画面で選べるのは 1〜3（0 と 4 以上は選択不可）。
- スイッチをOFFにしたとき、その行の優先度は破棄する。再度ONにしても元の値は復元せず、「今の件数＋1」が設定される。
- 各行に併記する金額は**前月の支出額**。そのカテゴリの前月（1日〜末日）の支出合計（固定費の自動計上分を含む）。月初でも確定した1か月分を見て判断できる（SCR-009と同じ基準）。前月の記録がない場合は「前月 ¥0」と表示する。
- **SCR-009から「‹」で戻ってきた場合**は、保存済みの設定ではなく、SCR-009へ進む前に選んでいた内容を表示する。
- フッターや「‹」でSCR-001などへ離れた場合、保存していない選択内容は破棄する（確認は出さない）。
- **削減対象の「すべて解除」はできない**（一次開発の仕様）。削減対象は常に1件以上必要で、0件では保存できない。削減対象を入れ替えたい場合は、不要なカテゴリをOFFにしてから別のカテゴリをONにする（3件選択中は他のスイッチが非活性のため。画面上で一時的に0件になっても、「次へ」を押すまではエラーにならない）。
- 戻る先は SCR-001（「‹」またはフッターの「ホーム」）。
