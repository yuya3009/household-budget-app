# 家計簿アプリ 詳細設計書

## 第18章 SCR-004 固定費登録画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-005（編集・削除は FUC-006, FUC-007 を SCR-005 経由で提供）

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `TextInput` | 名称（必須・30文字まで） |
| ② | `AmountInput` | 金額（必須） |
| ③ | `CategorySelector`（プルダウン） | カテゴリ（必須）。支出用カテゴリのみ |
| ④ | `SegmentedControl`（2択） | 計上頻度：毎月／毎年（必須） |
| ⑤ | `DatePicker`（カレンダー） | 開始日（必須）。**選んだ日付から計上日が決まる**。カレンダーの下に「選んだ日が毎月（毎年）の計上日になります」と補足を表示 |
| ⑥ | `MemoInput` | メモ（任意） |
| — | `NextPostingPreview` | 「次回の自動計上：2026/11/01 ¥85,000」の予告表示 |
| ⑦ | `PrimaryButton` ＋（編集モードのみ）危険ボタン「削除」＋ `ConfirmDialog` | 登録／保存／削除 |
| — | `AppBar`（戻るあり）, `PageMessage`, `AppFooter` | |

計上日の入力欄は設けない（開始日から自動で決める）。

### 2. バリエーション

#### 2-1. 画面モード

| モード | 遷移元 | ボタン | 入力欄の初期値 |
|---|---|---|---|
| 新規登録 | SCR-005「＋ 固定費を登録」 | 「登録する」 | 計上頻度は「毎月」、それ以外は空 |
| 編集 | SCR-005 の行タップ | 「保存する」＋「削除」 | 登録済みの値 |

#### 2-2. 計上頻度と計上日の決まり方

計上日は ⑤開始日 の日付から決まる。

| 計上頻度 | 計上日 | 例（開始日 2026/10/27） |
|---|---|---|
| 毎月（初期値） | 開始日の **dd**（日）を毎月の計上日とする | 毎月27日 |
| 毎年 | 開始日の **MM/dd**（月日）を毎年の計上日とする | 毎年10月27日 |

**その月に該当日がない場合**

| ケース | 計上日 |
|---|---|
| 毎月・開始日 1/31 | 2月は 2/28（うるう年は 2/29）、3月は 3/31。基準の「31日」は変わらず、その月にない場合だけ月末日にする |
| 毎月・開始日 4/30 など | 31日がある月でも 30日に計上（基準日は 30日） |
| 毎年・開始日 2/29 | うるう年は 2/29、それ以外の年は 2/28 |

#### 2-3. バリデーション

「登録する」押下時にチェックする。**エラーのある項目の数だけ**エラーメッセージを表示する。

| 項目 | 条件 | エラーメッセージ |
|---|---|---|
| ① 名称 | 空欄 | 「名称は入力してください」 |
| ① 名称 | 31文字以上 | 「名称は30文字以下にしてください」 |
| ② 金額 | 空欄 | 「金額を入力してください」 |
| ② 金額 | 0 | 「金額を入力してください」 |
| ② 金額 | 7桁以上 | 「999,999円までで入力してください」 |
| ③ カテゴリ | 未選択 | 「カテゴリは入力してください」 |
| ④ 計上頻度 | 未選択 | 「計上頻度は入力してください」 |
| ⑤ 開始日 | 未選択 | 「開始日は入力してください」 |

- 金額は1桁〜6桁（1〜999,999円）なら登録できる。
- 金額の空欄・0のメッセージは「金額を入力してください」に統一する（SCR-002・003 と同じ文言。共通の `AmountInput` で判定する）。
- 例：名称と金額が空欄の場合、「名称は入力してください」「金額を入力してください」の2つを表示する。
- エラーがある場合は登録せず、画面に留まる。

### 3. 注意点

- **カテゴリの選択肢**：デフォルトのカテゴリ（`default_category`=true）と、ログインユーザ自身が作成したカテゴリ（`category_creater_user`=ログインユーザ）だけを表示し、選択できる。いずれも支出用（category_type=01）に限る。他ユーザが作成したカテゴリは表示しない。
- **開始日**：必須項目。カレンダーで選択し、過去・未来どちらの日付も選択できる。選択した日付は**DATE型でそのまま保持**する（例：2026/10/15 を選択 → 2026-10-15）。
- **計上日を変えたいとき**：開始日を変更する（計上日は開始日から決まるため）。編集モードでも同じ。
- **編集モードでの更新**：金額・開始日・カテゴリ・名称・メモのいずれを更新しても、すでに自動計上された支出データは変更しない。これから計上される分だけに反映する（詳細は[SCR-005](19_詳細設計書_SCR-005固定費一覧.md)の注意点）。
- **初回の計上日（自動計上の開始ルール / FUC-009）**

  | ケース | 初回の計上日 | 例（今日 2026/10/11） |
  |---|---|---|
  | 開始日が明日以降 | 開始日そのもの | 開始日 2026/10/20・毎月 → 2026/10/20 |
  | 開始日が今日 | 毎月は**翌月**、毎年は**翌年**の同じ計上日（当日分は計上しない） | 開始日 2026/10/11・毎月 → 2026/11/11<br>開始日 2026/10/11・毎年 → 2027/10/11 |
  | 開始日が今日より前（今日が開始日を超えている） | **今日の月の翌月**以降で最初に来る計上日。過去分はさかのぼって計上しない | 開始日 2026/09/05・毎月 → 2026/11/05<br>開始日 2026/09/20・毎月 → 2026/11/20<br>開始日 2024/04/10・毎年 → 2027/04/10 |

  - 過去分を計上しないのは、登録後に過去の月の収支の数字が変わることを防ぐため。
  - 開始日が今日の場合に当日分を計上しないのは、その日の自動計上バッチが実行済みだと計上漏れになるため。
  - まとめると「開始日が明日以降なら開始日、今日以前なら今日の翌月以降で最初に来る計上日」となる。
  - 初回の計上日は登録時（編集で開始日・計上頻度を変えた場合は保存時）に計算し、`fixed_next_posting_date`（次回計上日）に保存する。自動計上バッチはこの値を見て計上する。
- **次回の自動計上（`NextPostingPreview`）**：計上頻度と開始日が入力されたら自動で表示する。どちらかの値が変わったら、変更後の値で自動的に再計算して表示する。計算は上記の「初回の計上日」のルールに従う。
- **登録・保存・削除の完了時**：完了したら固定費一覧（SCR-005）へ遷移し、ページ上部にメッセージを表示する（`PageMessage`、5秒後に自動で消える）。

  | 操作 | モード | メッセージ |
  |---|---|---|
  | 登録 | 新規登録 | 「固定費データを登録しました」 |
  | 保存 | 編集 | 「固定費データを保存しました。」 |
  | 削除 | 編集 | 「固定費データを削除しました」 |

- **削除確認モーダル**：編集モードで「削除」を押したら、共通の `ConfirmDialog` で「削除します。よろしいですか？」と表示する。ボタンは「削除」／「いいえ」。「削除」で論理削除（is_delete=true）して SCR-005 へ遷移、「いいえ」でモーダルを閉じて SCR-004 に留まる。
- **未保存のまま戻る場合**：入力途中でも、左上の「‹」やフッターで画面を離れるときに確認は出さない。入力内容は破棄する。
- 名称は重複を許可する（`fixed_name` の UNIQUE 制約はなし）。
- メモは200文字まで。
- 二重送信防止：送信中は「登録する」を非活性にする。
- 左上の「‹」は SCR-005 へ戻る（確認なし）。
- 登録時は `fixed_user` にログインユーザ（MVPでは単一ユーザ）のIDを設定する。画面上の入力項目はない。
