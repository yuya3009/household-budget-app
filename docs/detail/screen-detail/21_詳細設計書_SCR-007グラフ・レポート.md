# 家計簿アプリ 詳細設計書

## 第21章 SCR-007 グラフ・レポート画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-011, FUC-012, FUC-013

この画面には入力項目がないため、バリデーションはない。

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| — | `MonthSwitcher`（レポート用） | 表示月の切替。**全タブ共通**で、画面上部（タブの上）に置く |
| ① | `SegmentedControl`（3択） | 収支推移／カテゴリ別／削減対象のタブ |
| ② | `SummaryCard` ＋ `MonthlyBarChart` ＋ `PeriodSelect`（3/6/12か月） | 月次収支推移（FUC-011）。**SCR-001の④と同じ `MonthlyBarChart` を再利用** |
| ③ | `MonthlyBreakdownTable` | グラフ数値の表形式表示（月別の収入・支出・差額） |
| ④ | `SummaryCard` ＋ `CategoryDonutChart` ＋ `CategoryLegend` | 選択月のカテゴリ別支出（FUC-012） |
| ⑤ | `SummaryCard` ＋ `ReductionBarList`（横棒） | 削減対象カテゴリの内訳と、削減金額（目標）との比較（FUC-013） |
| — | `AppFooter`（レポートが active）, `EmptyState` | |

### 2. バリエーション

ワイヤフレームでは1画面にまとめて描かれているが、実際は**タブごとに表示を切り替える**。

| タブ | 表示するコンポーネント |
|---|---|
| 収支推移（初期値） | ②＋③。選択月を最終月として、期間：3か月／6か月（初期値）／12か月 |
| カテゴリ別 | ④（選択月） |
| 削減対象 | ⑤（選択月） |

| 状態 | 表示 |
|---|---|
| データあり | 各グラフ |
| データなし | グラフを出さず `EmptyState` を表示（SCR-001④と同じ考え方） |
| 削減対象が未設定（⑤） | 「支出削減で削減対象を設定してください」の案内＋ SCR-008 へのリンク |

#### 2-1. MonthSwitcher（レポート用）

| 項目 | 内容 |
|---|---|
| 選択単位 | **単月のみ** |
| 選択できる範囲 | **当月から半年前まで**（過去6か月）。**未来月は選択できない** |
| 右矢印 | 当月を表示しているとき非活性 |
| 左矢印 | 当月の半年前を表示しているとき非活性 |
| 初期値 | 当月（フッターの「レポート」から遷移した場合）／SCR-001で選択していた月（「詳しく見る」から遷移した場合。下記参照） |

選択月は3つのタブで共通。タブを切り替えても選択月は変わらない。

### 3. 注意点

- 遷移元は2つ。初期タブはどちらも「収支推移」。

  | 遷移元 | 選択月 | 期間 |
  |---|---|---|
  | フッターの「レポート」 | 当月 | 6か月（初期値） |
  | SCR-001の「詳しく見る」 | **SCR-001で選択していた月を引き継ぐ** | 6か月（SCR-001④と同じ範囲で表示する） |

  - 引き継ぐ月が選択範囲外の場合（SCR-001は未来月を最大6か月先まで、過去は最古データの月まで選べるため）は、範囲内の最も近い月に丸める。未来月 → 当月、半年より前 → 当月の半年前。
- ②の推移は、選択月を含む直近N か月（3/6/12）。選択月が当月でなくても同様に、選択月を最終月として過去へさかのぼる。
- ④カテゴリ別は**選択月**のカテゴリ別支出。表示件数が多い場合は上位5件＋「その他」にまとめる（ワイヤフレームの凡例に準拠）。
- ⑤は SCR-008 の優先度順に並べる。バーの幅は最大金額を100%とした比率。「支出の○%」は削減対象合計÷選択月の支出合計。前月比は前月に支出がない場合「—」を表示する。
- **⑤の削減金額（目標）との比較**：SCR-009で設定したカテゴリごとの削減金額（`reduction_amount`、1か月あたり）と比べて表示する。
  - 各カテゴリの行に、削減金額（目標）と、選択月の支出額を並べて表示する。
  - 削減金額が未設定（SCR-009未保存）のカテゴリは、比較は表示せず金額と前月比のみを出す。
  - **比較は前月比で判定する**：削減実績＝前月の支出額−選択月の支出額。削減実績が削減金額（目標）以上なら達成。表示例：「目標 ¥10,000 ／ 実績 ¥4,200 削減」。
  - 削減実績がマイナス（前月より支出が増えた）の場合は「実績 ¥X 増加」と表示し、未達成とする。前月に支出がない場合は「—」を表示して判定しない。
- グラフの色だけに意味を持たせない（収入／支出の凡例を必ず併記し、ドーナツは金額も文字で表示）。
- 集計（月次合計・カテゴリ別合計・削減対象合計）はDB側の集計関数で行う（[技術スタック書](06_技術スタック書.md)の方針）。

### 4. 未決事項

1. 削減金額は月ごとの履歴を持たない（現在の設定値が1つ）。過去の月を選択したときも、現在の削減金額で比較してよいか。
2. 「その他」の名前の重なり：ドーナツで上位5件以外をまとめる「その他」と、デフォルトカテゴリの「その他」が同名になる。まとめた方を「上記以外」などにするか。
3. 固定費の自動計上分を、削減対象の合計に含めるか（含める場合、「うち固定費」を分けて見せるか）。
4. 前月比の表示対象：削減対象カテゴリ全部に出すか、増えた額が最も大きいものだけにするか。
5. 選んだ期間が長くデータが足りない場合（例：12か月を選んだがデータは3か月分）、データのない月を 0 として表示するか、データのある月だけ表示するか。
6. 「支出の○%」の端数処理（SCR-005と同じ切り捨てでよいか）。
7. ③月別内訳表の並び順（新しい月が上か）と、12か月の場合の全件表示の可否。
8. 他の画面へ移動して戻ったとき、前回のタブ・期間・選択月を保持するか、毎回初期値に戻すか。
9. 期間（3/6/12か月）に12か月が残っているが、選択できる月は半年前までに限った。12か月の推移を選んだ場合に、半年より古い月まで表示してよいか（表示範囲と選択範囲の整合）。
