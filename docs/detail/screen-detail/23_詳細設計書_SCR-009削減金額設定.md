# 家計簿アプリ 詳細設計書

## 第23章 SCR-009 削減金額設定画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-014

[SCR-008 支出削減設定](22_詳細設計書_SCR-008支出削減設定.md)で削減対象にしたカテゴリごとに、1か月あたりの削減金額を入力して保存する画面。SCR-008で選んだ内容（削減対象・優先度）と本画面の削減金額を、「保存する」でまとめてDBに保存する。

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `SummaryCard` | 削減金額の合計（／月）。入力に合わせてリアルタイムに再計算 |
| ② | `ListItem`（SCR-009用） | SCR-008で削減対象にしたカテゴリを優先度順に表示。先頭に優先度、サブテキストに前月の支出額（うち固定費） |
| ③ | `AmountInput`（ListItem内） | 削減金額（必須） |
| ④ | 削減後の目安（ListItem内のテキスト） | 「削減後の目安 ¥X」＝前月の支出額 − 削減金額 |
| ⑤ | `PrimaryButton`「保存する」 | 削減対象・優先度・削減金額をまとめて保存 |
| — | `AppBar`（戻るあり）, `PageMessage`（ページ上部のメッセージ）, `AppFooter` | |

### 2. バリエーション

#### 2-1. 削減金額の初期値

| カテゴリ | 初期値 |
|---|---|
| すでに削減対象として保存済み（category_classificationにある） | 保存済みの `reduction_amount` |
| 今回SCR-008で新たに削減対象にした | 空欄 |

#### 2-2. バリデーション

「保存する」押下時にチェックする。エラーのある行それぞれにエラーメッセージを表示する。

| 条件 | エラーメッセージ |
|---|---|
| 空欄 | 「削減金額を入力してください」 |
| 0 | 「削減金額を入力してください」 |
| 7桁以上 | 「999,999円までで入力してください」 |

- 削減金額が**1行でも**空欄または0の状態で「保存する」を押したら、「削減金額を入力してください」を表示する（エラーのある行ごとに、その行に表示する）。
- 7桁以上の数値が**1行でも**あった状態で「保存する」を押したら、「999,999円までで入力してください」を表示する。
- 金額の判定は共通の `AmountInput` で行う（SCR-002・003・004と同じ範囲：1〜999,999円）。
- エラーが1行でもある場合は保存せず、画面に留まる（SCR-008 へも遷移しない）。

### 3. 注意点

- SCR-006 で削除されたカテゴリは、この画面に表示しない（削減対象だった場合は、削除時に優先度が詰め直され、削減対象から外れている）。
- **削減金額はカテゴリ単位**。そのカテゴリの固定費・変動費の両方を合わせた支出から、どれだけ減らすかを表す。判断材料として、サブテキストに「前月 ¥X（うち固定費 ¥Y）」を表示する。
  - 前月の支出額：そのカテゴリの**前月**（1日〜末日）の支出合計（固定費の自動計上分を含む）。月の途中の金額ではなく確定した1か月分のため、月初でも削減金額の目安にしやすい。
  - うち固定費：前月に固定費から自動計上された分。0円の場合は「（うち固定費）」の表記を省略する。
- **金額の端数は切り捨てて表示する**：①削減金額の合計と④削減後の目安は、1円未満が出る場合は切り捨てた金額で表示する（入力は整数のため、通常は端数は出ない）。
- **前月の記録がない場合**（利用開始直後など）は「前月 ¥0」と表示し、削減後の目安は ¥0 になる。
- **削減金額が前月の支出額を上回っても保存できる**（月ごとの変動があるため）。その場合、④削減後の目安は ¥0 と表示する。
- **保存処理**：カテゴリ区分一括保存API（[API仕様書 4-2](09_API仕様書.md)）に、SCR-008で選んだ削減対象・優先度と、本画面の削減金額をまとめて送る。保存は1トランザクションで行い、失敗した場合は何も変更しない。
- **保存完了時**：バリデーションが通ってデータを登録できたら、ページ上部に「**支出削減頑張りましょう**」とメッセージを表示し、そのあと **SCR-008 へ遷移**する（`PageMessage`、5秒後に自動で消える。SCR-002 と同じく、遷移先の SCR-008 でも表示したままにする）。
  - 遷移後の SCR-008 は、保存した内容（削減対象・優先度）を表示する。
  - 保存失敗時は画面に留まり、エラーメッセージを表示する（完了メッセージは出さない）。
- **「‹」で戻る**：SCR-008 へ戻る。SCR-008での選択内容は保持する。本画面で入力した削減金額も保持し、再度SCR-009へ進んだときに表示する（SCR-008で維持対象に戻したカテゴリの入力値は破棄する）。
- フッターでSCR-001などへ離れた場合、保存していない内容（SCR-008の選択・本画面の入力）はすべて破棄する（確認は出さない）。
- 二重送信防止：送信中は「保存する」を非活性にする。
