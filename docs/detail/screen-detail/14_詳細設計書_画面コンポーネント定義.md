### 2. 共通コンポーネント一覧

複数画面で使うものは共通化し、画面ごとに似て非なる部品を作らない（[技術スタック書](06_技術スタック書.md)のReactのデメリット対策）。

| コンポーネント | 用途 | 使用画面 | バリエーション |
|---|---|---|---|
| `AppFooter` | 「ホーム／収支入力／レポート」の3項目タブバー | **全画面** | 現在画面に対応する項目を強調（active） |
| `AppBar` | 画面タイトル＋左上の戻る「‹」 | 全画面 | 戻るあり（SCR-003〜006, 008, 009）／なし（SCR-001, 002, 007） |
| `MonthSwitcher` | 単月の年月切替（‹ 2026年10月 ›） | SCR-001, 003, 007 | 左右矢印の活性／非活性。選択範囲は画面ごとに props で渡す（SCR-001・003：最古データの月〜当月＋6か月／SCR-007：当月の半年前〜当月で未来月不可） |
| `SegmentedControl` | 2〜3択の切替 | SCR-002, 004, 006, 007 | 2択（支出/収入、毎月/毎年）／3択（レポートのタブ） |
| `AmountInput` | 金額入力（数値キーボード） | SCR-002, 003, 004, 009 | 通常／エラー |
| `DatePicker` | 日付選択（カレンダー） | SCR-002, 003, 004 | 通常／エラー |
| `CategorySelector` | カテゴリ選択 | SCR-002, 003, 004 | アイコングリッド（SCR-002）／プルダウン（SCR-003, 004）。候補は種別で切替 |
| `IconSelector` | アイコン候補のグリッドから1つ選ぶ | SCR-006 | 未選択／選択中／エラー |
| `TextInput` | 1行テキスト入力（文字数上限あり） | SCR-004, 006 | 通常／エラー |
| `MemoInput` | メモ（任意・200文字まで） | SCR-002, 003, 004 | 通常／文字数超過エラー |
| `ListItem` | アイコン＋名称＋金額＋「›」の行 | SCR-003, 005, 006, 008, 009 | 下表参照 |
| `PrimaryButton` | 画面下部の主ボタン | SCR-002, 004, 005, 006, 008, 009 | 通常／非活性／送信中／危険（削除） |
| `ConfirmDialog` | 削除などの確認モーダル（詳細は「ConfirmDialog の定義」参照） | SCR-003, 004, 006 | 削除確認（メッセージ・ボタン文言を props で切替） |
| `Toast` | 完了・失敗の通知 | SCR-002〜006, 008, 009 | 成功／エラー |
| `BottomSheet` | 下から出る編集シート | SCR-003, 006 | 開／閉 |
| `SummaryCard` | 見出し＋中身のカード | SCR-001, 005, 007, 009 | リンクあり／なし |
| `EmptyState` | データ0件の案内表示 | SCR-003, 005, 006, 007 | 画面ごとの文言 |
| `MonthlyBarChart` | 月次の収入／支出の棒グラフ | SCR-001, 007 | 6か月固定（SCR-001）／3・6・12か月（SCR-007） |

`ListItem` のバリエーション

| 使用画面 | 右側の表示 | 補足 |
|---|---|---|
| SCR-003 | 金額（支出は−、収入は＋）＋「›」 | 固定費由来の行は「固定費」タグ付き・「›」なし（編集・削除不可） |
| SCR-005 | 金額＋「›」 | サブテキストに「カテゴリ・計上日」 |
| SCR-006 | 「›」（自分が作成したカテゴリのみ） | デフォルトカテゴリは「標準」タグ付き・「›」なし（編集・削除不可）。サブテキストに説明 |
| SCR-008 | 優先度プルダウン（1〜3）＋ON/OFFスイッチ | 「削減／維持」タグ、前月支出額を併記 |
| SCR-009 | 削減金額の `AmountInput` | 先頭に優先度、サブテキストに前月支出額（うち固定費）と削減後の目安 |

#### ConfirmDialog の定義

画面をまたいで使う確認モーダル。画面ごとに専用のモーダルは作らず、このコンポーネントを使う。

| props | 内容 | SCR-003（収支の削除）での値 |
|---|---|---|
| message | 確認メッセージ | 「支出を削除しますか？」／「収入を削除しますか？」（種別で出し分け） |
| confirmLabel | 実行ボタンの文言 | 「削除」 |
| cancelLabel | 取消ボタンの文言 | 「いいえ」 |
| onConfirm | 実行ボタン押下時の処理 | `is_delete` を true にして論理削除 |
| onCancel | 取消ボタン押下時の処理 | モーダルを閉じるだけ（データは変更しない） |

- 表示中は背面の画面を操作できない（背景を暗くする）。
- 実行ボタン押下後、処理中は両ボタンを非活性にして二重実行を防ぐ。
- 取消ボタン押下時は、モーダルを非表示にして呼び出し元の画面に戻る。
- 呼び出し元：SCR-003（収支の削除）、SCR-004（固定費の削除）、SCR-006（カテゴリの削除）。

| 呼び出し元 | message | confirmLabel | cancelLabel |
|---|---|---|---|
| SCR-003 | 「支出を削除しますか？」／「収入を削除しますか？」 | 「削除」 | 「いいえ」 |
| SCR-004 | 「削除します。よろしいですか？」 | 「削除」 | 「いいえ」 |
| SCR-006 | 「カテゴリを削除します。よろしいですか？」 | 「削除」 | 「いいえ」 |

- 取消ボタン（cancelLabel）の文言は、全画面で「いいえ」に統一する。

### 3. 画面横断の注意点

| 項目 | 内容 |
|---|---|
| フッター | 全画面で同一の `AppFooter`。アプリ全体のレイアウト側に置き、各画面は active 項目を現在のルートから自動で決める（画面ごとに props で渡さない） |
| 戻る操作 | SCR-003/005/006/008 は「‹」またはフッター「ホーム」で SCR-001 へ。SCR-004 は「‹」で SCR-005 へ。SCR-009 は「‹」で SCR-008 へ（選択内容を保持） |
| 金額の入力制約 | 全画面共通で 1〜999,999円。`AmountInput` 内にバリデーションを持たせ、画面ごとに重複実装しない |
| 日付・年月 | 年月の範囲判定（最古月・最大月）のロジックは `MonthSwitcher` の1か所に集約する |
| 削除 | すべて論理削除（is_delete=true）。確認ダイアログは `ConfirmDialog` を共通利用 |
| 通知 | 登録・保存・削除の完了／失敗は `Toast` で通知する |
| 幅 | スマートフォン幅（360px基準）で設計する |
