# 家計簿アプリ 詳細設計書

## 第15章 SCR-001 ホーム（ダッシュボード）画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-011

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `MenuItem` ×4 | 収支一覧／固定費／カテゴリ設定／支出削減。**4つとも同一コンポーネント**で、ラベル・アイコン・遷移先（SCR-003 / 005 / 006 / 008）だけ変える。押下で各画面へ遷移 |
| ② | `MonthSwitcher` | 年月切替 |
| ③ | `SummaryCard` ＋ `BalanceSummary` | 今月の収支（差額・収入・支出・うち固定費） |
| ④ | `SummaryCard` ＋ `MonthlyBarChart` | 月次収支推移。「詳しく見る」→ SCR-007（②で選択中の月を引き継ぐ） |
| — | `AppFooter` | 全画面共通（ホームが active） |

③と④は**外枠（`SummaryCard`）を共通**にし、中身だけ差し替える。

```
HomePage
├─ MenuItem ×4
├─ MonthSwitcher
├─ SummaryCard(今月の収支)    └─ BalanceSummary
├─ SummaryCard(月次収支推移)  └─ MonthlyBarChart
└─ AppFooter
```

### 2. バリエーション

画面全体のバリエーションはない。部品単位の状態のみ。

| 部品 | 状態 |
|---|---|
| `MonthSwitcher` | 左矢印の活性／非活性、右矢印の活性／非活性 |
| ③ | データあり／0（各金額に 0 を表示） |
| ④ | グラフ表示／グラフ非表示（0の場合） |

### 3. 注意点

- **年月は単月のみ**。複数月の選択はできない。初期値は当月。
- 選択できる最古月は、**支出・収入データのうち最も古い日付の月**。データが1件もない場合は当月。
- 選択できる最大月は、**当月を1か月目として7か月目（当月＋6か月）**。例：今日が 2026/10 なら 2027/04 まで。7か月目で右矢印を非活性にし、それ以降の未来月は選択できない。
- ③の集計期間は選択月の1日〜末日（例：2026年10月 → 2026/10/01〜2026/10/31）。固定費の自動計上分（FUC-009）を含む。
- ④は**選択月を含む過去6か月分**（例：2026年10月 → 5〜10月）。
- 表示する6か月の収入・支出がすべて 0 の場合、③は 0 を表示し、④はグラフを表示しない。一部の月だけ 0 の場合は、その月の棒を 0 で描画する。
- ①は横1列に4つ並べる（幅360px基準で1つあたり約77px。ラベルは最長6文字「カテゴリ設定」が収まるフォントサイズにする）。
- ①の遷移先が4つとも異なるため、遷移先は props で受け取り、コンポーネント内に画面固有の分岐を持たせない。

### 4. 確認済み事項

未決事項はなし。

1. 未来月は「今日から**半年分**」（誤記ではなく確定）。7か月目＝当月＋6か月まで選択可とする。
2. 「過去6か月分」は、選択月を含む6か月とする。
