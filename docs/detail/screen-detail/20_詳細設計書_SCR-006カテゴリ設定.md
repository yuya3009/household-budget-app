# 家計簿アプリ 詳細設計書

## 第20章 SCR-006 カテゴリ設定画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-015, FUC-016, FUC-017, FUC-018

削減対象・優先度の設定は[SCR-008 支出削減設定](22_詳細設計書_SCR-008支出削減設定.md)で行う。本画面はカテゴリそのものの追加・編集・削除だけを扱う。

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `SegmentedControl`（2択） | 支出／収入の切替。初期値は「支出」 |
| ② | `ListItem`（SCR-006用） | カテゴリ一覧（FUC-018）。デフォルトカテゴリ → 自分が作成したカテゴリの順 |
| ③ | `ListItem` の「›」 | 自分が作成したカテゴリを押下すると、カテゴリ編集シート（編集）を開く |
| ④ | `PrimaryButton`「＋ カテゴリを追加」 | カテゴリ編集シート（新規）を開く |
| ⑤ | `BottomSheet`（カテゴリ編集シート） | `TextInput`（カテゴリ名）＋ `IconSelector`（アイコン）＋ `TextInput`（説明）＋ ボタン |
| — | `AppBar`（戻るあり）, `ConfirmDialog`（削除確認モーダル）, `PageMessage`（ページ上部のメッセージ）, `EmptyState`, `AppFooter` | |

```
CategorySettingsPage
├─ SegmentedControl(支出／収入)
├─ ListItem × n
├─ PrimaryButton(＋ カテゴリを追加)
└─ BottomSheet(カテゴリ編集シート)
    ├─ TextInput(カテゴリ名)
    ├─ IconSelector
    ├─ TextInput(説明)
    └─ PrimaryButton(保存する) ＋ 危険ボタン(削除・編集時のみ)
```

### 2. バリエーション

#### 2-1. 一覧の行

| 行の種類 | 表示 | 押下時 |
|---|---|---|
| デフォルトカテゴリ（`default_category`=true） | 名称＋「標準」タグ。「›」なし | 何もしない（編集・削除不可） |
| 自分が作成したカテゴリ | 名称＋「›」。サブテキストに説明（ある場合） | カテゴリ編集シート（編集）を開く |

自分が作成したカテゴリが0件のときは、一覧の下に `EmptyState`「まだ自分のカテゴリはありません」を表示する（デフォルトカテゴリは常に表示）。

#### 2-2. カテゴリ編集シートのモード

| モード | 開き方 | タイトル | ボタン | 入力欄の初期値 |
|---|---|---|---|---|
| 新規 | ④「＋ カテゴリを追加」 | 「カテゴリを追加」 | 「保存する」 | 空。種別はページ上部のタブ（①）で選択中の値（支出／収入） |
| 編集 | ③自分が作成したカテゴリの行 | 「カテゴリを編集」 | 「保存する」＋「削除」 | 登録済みの値 |

種別（支出用／収入用）はシート内に「支出カテゴリ」「収入カテゴリ」と表示する。

| モード | 種別の決まり方 | 変更 |
|---|---|---|
| 新規 | ページ上部のタブで決まる。「支出」タブ → 支出カテゴリ（category_type=01）、「収入」タブ → 収入カテゴリ（category_type=02） | 種別を変えたい場合は、シートを閉じてタブを切り替えてから追加する |
| 編集 | 登録済みの種別 | **変更不可**（支出→収入、収入→支出のどちらも不可） |

#### 2-3. バリデーション

「保存する」押下時にチェックする。エラーのある項目の数だけエラーメッセージを表示する（SCR-004と同じ考え方）。

| 項目 | 条件 | エラーメッセージ |
|---|---|---|
| カテゴリ名 | 空欄 | 「カテゴリ名は入力してください」 |
| カテゴリ名 | 31文字以上 | 「カテゴリ名は30文字以下にしてください」 |
| カテゴリ名 | 既存カテゴリと重複（APIの`409 DUPLICATE_CATEGORY_NAME`） | 「同じ名前のカテゴリがすでにあります」 |
| アイコン | 未選択（空欄） | 「アイコンは一つ選択してください」 |
| 説明 | 101文字以上 | 「説明は100文字以下にしてください」 |
| 種別（編集時のみ） | 支出→収入、収入→支出への変更 | 画面上で変更できないため、エラーメッセージは出さない（APIでも種別の変更は受け付けない） |

- カテゴリ名の30文字超過チェックは、新規作成・更新のどちらでも行う。

### 3. 注意点

- **登録する種別はページ上部のタブで決まる**：「支出」タブを押した状態で追加したら支出カテゴリ、「収入」タブを押した状態で追加したら収入カテゴリとして登録する。追加後は、登録した種別のタブの一覧に表示される。
- **編集・削除できるのは自分が作成したカテゴリのみ**。デフォルトカテゴリは一覧に表示するが、操作できない。
- **種別は編集時に変更不可**：支出用⇔収入用を変えると、既存の支出・収入・固定費データとの整合が崩れるため。誤った種別で作った場合は、削除してから作り直す（SCR-003の収支区分と同じ考え方）。
- **アイコン**：`IconSelector` で、アプリで用意したアイコン候補（**24個**）から**1つだけ**選ぶ。選んだアイコンのURLを `category_icon` に保存する。画像のアップロードはしない。
  - 候補は種別（タブ）によって出し分ける。支出カテゴリでは「支出（生活）」「支出（趣味・付き合い）」「汎用」の20個、収入カテゴリでは「収入」「汎用」の6個を表示する。
  - デフォルトカテゴリのアイコンも、この24個の中から割り当てる（見た目を統一するため）。
  - 24個はグリッド（4列×6行）で表示し、スクロールなしで選べる大きさにする。

    | 区分 | 個数 | アイコン |
    |---|---|---|
    | 支出（生活） | 10 | 食事、電車・バス、車、家、電気・水道、スマホ・通信、医療、服、美容、日用品 |
    | 支出（趣味・付き合い） | 8 | ゲーム・娯楽、旅行、ペット、子ども、教育・本、ギフト・交際費、保険・お守り、サブスク |
    | 収入 | 4 | 給与、ボーナス・臨時収入、副業、お小遣い |
    | 汎用（支出・収入共通） | 2 | その他、貯金・投資 |
- **削除**：
  - 編集シートの「削除」ボタンを押下すると、確認モーダル（`ConfirmDialog`）を表示する。

    | 項目 | 内容 |
    |---|---|
    | メッセージ | 「カテゴリを削除します。よろしいですか？」 |
    | ボタン | 「いいえ」／「削除」 |
    | 「いいえ」押下 | モーダルを非表示にする（削除しない。編集シートに戻る） |
    | 「削除」押下 | `is_delete` を true にして**論理削除**する。モーダルとシートを閉じて一覧を再取得し、ページ上部に「カテゴリを削除しました」を表示する |
  - 削除しても、そのカテゴリで記録した支出・収入は残る。収支一覧（SCR-003）やレポート（SCR-007）では、削除済みカテゴリの名称をそのまま表示する。
  - 削除すると、そのカテゴリは削減対象からも外れる（category_classificationも論理削除）。
  - **削減対象だったカテゴリを削除した場合は、残りの削減対象の優先度を自動で詰め直す**（同じトランザクション）。削減金額は変更しない。

    | 削除前（優先度） | 削除するカテゴリ | 削除後 |
    |---|---|---|
    | 外食1・娯楽2・衣服3 | 娯楽（2番目） | 外食1（変更なし）・衣服2 |
    | 外食1・娯楽2・衣服3 | 外食（1番目） | 娯楽1・衣服2 |
    | 外食1・娯楽2・衣服3 | 衣服（3番目） | 外食1・娯楽2（変更なし） |

  - 削減対象が1件だけで、そのカテゴリを削除した場合は、削減対象が0件になる。SCR-008 を開くと削減対象はすべてOFFの状態で表示される（再設定が必要）。
  - **固定費で使用中のカテゴリは削除できない**。APIが `409 CATEGORY_IN_USE` を返した場合は、モーダルを閉じてページ上部にエラー「固定費で使用中のため削除できません。先に固定費のカテゴリを変更してください」を表示する。
  - 削除したカテゴリは、SCR-002・SCR-003・SCR-004のカテゴリ選択肢、**SCR-008・SCR-009の一覧**、SCR-007の削減対象タブに表示されなくなる。
- **登録（新規）の完了時**：「保存する」を押下し、バリデーション・入力値に問題がなければデータを登録する。登録後は次のとおり。
  - ページ上部に「カテゴリを登録しました」と表示する（`PageMessage`、5秒後に自動で消える）。
  - **カテゴリ設定画面に留まる**（他画面へは遷移しない）。シートを閉じて一覧を再取得し、作成したカテゴリを一覧に表示する（一覧の末尾）。
  - バリデーションエラーがある場合は登録せず、シートを開いたままエラーメッセージを表示する。
- **更新（編集）の完了時**：シートを閉じて一覧を再取得し、ページ上部に「カテゴリを保存しました」と表示する。カテゴリ設定画面に留まる。
- **シートを閉じる**：「✕」または背景タップで閉じる。入力途中でも確認は出さず、入力内容は破棄する（SCR-003の編集シートと同じ）。
- 二重送信防止：送信中は「保存する」「削除」を非活性にする。
- 登録時は `category_creater_user` にログインユーザ（MVPでは単一ユーザ）のIDを設定し、`default_category` は false とする。画面上の入力項目はない。
- 戻る先は SCR-001（「‹」またはフッターの「ホーム」）。
- **一覧の並び順**：デフォルトカテゴリ → 自分が作成したカテゴリの順で、自作カテゴリは作成順に固定する。ユーザが並び順（作成日順など）を変更できる機能は、2次開発で対応する（一次開発の対象外）。
