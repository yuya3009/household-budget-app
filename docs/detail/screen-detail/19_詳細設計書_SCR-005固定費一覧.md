# 家計簿アプリ 詳細設計書

## 第19章 SCR-005 固定費一覧画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
編集画面の構成・バリデーション・注意点は[SCR-004](18_詳細設計書_SCR-004固定費登録.md)と同じ。
関連機能：FUC-006, FUC-007, FUC-008

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `SummaryCard`（中身：月額換算合計・年額換算） | 固定費の月額換算合計 |
| ② | `GroupHeader` ＋ `ListItem` | 毎月／毎年でグルーピング（FUC-008）。サブテキストに「カテゴリ・計上日」（計上日は開始日から決まる：毎月dd／毎年MM/dd） |
| ③ | `ListItem` の「›」 | 固定費データを押下すると、編集画面（SCR-004 編集モード）へ遷移する（FUC-006） |
| ④ | `PrimaryButton`「＋ 固定費を登録」 | SCR-004（新規）へ遷移 |
| — | `AppBar`（戻るあり）, `PageMessage`, `EmptyState`, `AppFooter` | |

### 2. バリエーション

#### 2-1. 一覧

| 切替要素 | パターン |
|---|---|
| 一覧 | 毎月・毎年の両方あり／片方のみ（0件のグループは見出しごと非表示）／全件0（`EmptyState`＋合計 ¥0） |

#### 2-2. 編集画面（行を押下した後）

| 項目 | 内容 |
|---|---|
| 構成 | **SCR-004 と同じ構成**（名称・金額・カテゴリ・計上頻度・開始日・メモ・次回の自動計上） |
| 初期表示 | 押下した固定費の**登録済みの値がすでに表示されている** |
| ボタン | 「保存する」＋「削除」 |
| バリデーション | SCR-004 と同じ（「〇〇は入力してください」、金額の0・7桁以上、名称30文字超 など） |
| 注意点 | SCR-004 と同じ（カテゴリの選択肢、開始日から計上日を決める、次回計上日の再計算 など） |
| 保存完了 | SCR-005 へ戻り、「固定費データを保存しました。」を表示 |
| 削除 | 確認モーダル「削除します。よろしいですか？」→「削除」で論理削除して SCR-005 へ戻り、「固定費データを削除しました」を表示 |

### 3. 注意点

- **編集は過去の計上分に影響させない**：編集で変更した内容は、**これから計上される分だけ**に反映する。すでに自動計上された支出データ（収支一覧の「固定費」タグ付きの行）は書き換えない。
  - **金額**を更新しても、過去に計上された支出データの金額は変更しない。
  - **日付（開始日）**を更新しても、過去に計上された支出データの日付は変更しない。
  - **カテゴリ・名称・メモ**を更新しても、過去に計上された支出データは変更しない。
  - 例：毎月27日・¥85,000 で 9/27・10/27 に計上済みの固定費を、11月に ¥90,000・毎月25日 へ変更 → 9/27・10/27 の行は ¥85,000 のまま。次回以降は ¥90,000 で25日に計上。
  - 開始日・計上頻度を変更した場合、次回計上日は SCR-004 のルール（開始日が明日以降なら開始日、今日以前なら今日の翌月以降で最初に来る計上日）で再計算する。
- **削除も過去の計上分に影響させない**：固定費を削除（論理削除）しても、すでに計上された支出データは残す。削除後は自動計上されなくなる。計上済みの行は収支一覧（SCR-003）でも編集・削除できないため、実績として残り続ける。
- 月額換算合計 ＝ 毎月分の合計 ＋ 毎年分の合計 ÷ 12。**1円未満は切り捨て**る。例：毎年分の合計 ¥53,900 → ¥4,491（4,491.66…を切り捨て）。
- 年額換算は「毎月分×12＋毎年分」で算出する（月額換算合計×12 ではない。切り捨てた端数のずれを出さないため）。
- 削除は一覧では行わず、編集画面（SCR-004 編集モード）から行う。
- 保存・削除後は一覧と合計を再取得する。
- 戻る先は SCR-001（「‹」またはフッターの「ホーム」）。
