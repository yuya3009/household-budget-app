# 家計簿アプリ 詳細設計書

## 第16章 SCR-002 収支入力画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
関連機能：FUC-001

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `SegmentedControl`（2択） | 支出／収入 |
| ② | `AmountInput` | 金額（必須） |
| ③ | `DatePicker` | 日付（必須）。初期値は当日 |
| ④ | `CategorySelector`（グリッド） | カテゴリ（必須）。categoriesのデフォルト＋ユーザ作成分 |
| ⑤ | `MemoInput` | メモ（任意） |
| ⑥ | `PrimaryButton`「記録する」＋「続けて入力する」チェック | 登録 |
| — | `PageMessage`（ページ上部のメッセージ）, `AppFooter`（収支入力が active） | 登録完了メッセージを表示 |

### 2. バリエーション

#### 2-1. ① 種別（支出／収入）

| 状態 | 見た目 |
|---|---|
| 選択中 | 背景が**水色** |
| 未選択 | 背景が**白色** |

- 必ずどちらか一方が選択された状態になる。**両方未選択、両方選択の状態はありえない**。
- 初期表示は「支出」が選択中。
- 切り替えると、④のカテゴリ候補が変わる（支出用 category_type=01／収入用 02）。登録先テーブルも変わる（expenditures／incomes）。

#### 2-2. ② 金額

| 入力内容 | 結果 |
|---|---|
| 空欄 | エラー「金額を入力してください」 |
| 0 | エラー「金額を入力してください」 |
| 1桁〜6桁の数値（1〜999,999） | 登録可 |
| 7桁以上の数値 | エラー「999,999円までで入力してください」 |

#### 2-3. ③ 日付

| 状態 | 結果 |
|---|---|
| 初期表示 | **今日の日付**がデフォルト値 |
| 未入力（日付を消した場合） | 登録不可（必須） |
| カレンダーで選択 | **過去・未来を問わず、どの日付でも登録可** |

#### 2-4. ④ カテゴリ

- 選択できるのは**必ず1つ**。2つ以上は選択できない（別のカテゴリをタップしたら、前の選択は解除され切り替わる）。
- 未選択のまま「記録する」を押した場合は登録不可。エラー「カテゴリを一つ選択してください。」を表示する。

#### 2-5. 「続けて入力する」チェック

| 状態 | 登録後の動作 |
|---|---|
| OFF（初期値） | 登録完了後、ホーム画面（SCR-001）へ遷移 |
| ON | 登録完了後、収支入力画面に留まる（下記「入力値の扱い」参照） |

### 3. 注意点

- **登録完了メッセージ**：「記録する」を押して登録できたら、ページ上部にメッセージを表示する。
  - 「支出」を選択して登録した場合 → 「支出を登録しました」
  - 「収入」を選択して登録した場合 → 「収入を登録しました」
- **登録後の遷移**：登録できたら、ホーム画面へ遷移する。ただし「続けて入力する」にチェックを入れて登録した場合は、収支入力画面に留まる。
- **入力値の扱い（続けて入力する場合）**：1回目に入力していた値は捨てて、画面に表示しない。入力欄は初期状態に戻す。
  - ① 種別：「支出」
  - ② 金額・④ カテゴリ・⑤ メモ：空
  - ③ 日付：当日
  - 「続けて入力する」チェック：**OFF** に戻す
- **メッセージの表示**：ホーム画面へ遷移する場合も、登録完了メッセージを表示したままにする（遷移先のホーム画面でも表示される）。メッセージは**表示から5秒後に自動で消える**。画面遷移をまたいでも、5秒のカウントは表示開始時点から継続する。
- 金額は数値キーボードを表示し、全角・小数点・マイナスは受け付けない。
- メモは200文字まで。
- **種別を切り替えたら選択済みカテゴリをクリア**する（支出用カテゴリのまま収入として登録される不整合を防ぐ）。
- 二重送信防止：送信中は「記録する」を非活性にする。
- 登録に失敗した場合は、入力値を保持したままエラー通知を表示し、完了メッセージは出さない。
- ワイヤフレームの金額下の補足は「0〜999,999円」だが、仕様は「1〜999,999円」。実装時に補足文言を「1〜999,999円」へ修正する。
