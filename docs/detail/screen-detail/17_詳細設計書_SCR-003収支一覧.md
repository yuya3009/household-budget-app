# 家計簿アプリ 詳細設計書

## 第17章 SCR-003 収支一覧画面

共通コンポーネントは[第14章](14_詳細設計書_画面コンポーネント定義.md)を参照。番号（①〜）は[ワイヤフレーム](10_ワイヤフレーム.html)に対応する。
入力部品のバリエーション（金額・日付・カテゴリのエラーなど）は[SCR-002](16_詳細設計書_SCR-002収支入力.md)とほぼ同じ。
関連機能：FUC-002, FUC-003, FUC-004

---

### 1. 使用コンポーネント

| 番号 | コンポーネント | 内容 |
|---|---|---|
| ① | `MonthSwitcher` | 表示月の切替（SCR-001と同一コンポーネント・**同じルール**）。単月のみ。最古月は支出・収入データの最も古い日付の月、最大月は当月を1か月目として7か月目（当月＋6か月）で、右矢印は7か月目で非活性 |
| ② | `FilterChips` | 種別（すべて／支出／収入）＋カテゴリ絞り込み |
| — | `MonthTotalRow` | 選択月の収入合計・支出合計。**絞り込み（②）の影響を受けず、常に月全体の値を表示**する（SCR-001の今月の収支と一致） |
| ③ | `DateGroupHeader` ＋ `ListItem` | 日付ごとにグルーピング（FUC-004） |
| ④ | `BottomSheet`（編集シート） | 支出または収入の行を押下すると**ページ下部に表示**される編集コンポーネント（FUC-002） |
| ④内 | `SegmentedControl`（表示のみ）/ `AmountInput` / `DatePicker` / `CategorySelector`（プルダウン）/ `MemoInput` | SCR-002と同じ入力部品を再利用 |
| ⑤ | `PrimaryButton`（危険）「削除」 | 押下で確認モーダルを表示（FUC-003） |
| ⑤ | `ConfirmDialog`（**共通コンポーネント**） | 削除確認モーダル。定義は[第14章](14_詳細設計書_画面コンポーネント定義.md)の「ConfirmDialog」を参照 |
| — | `AppBar`（戻るあり）, `PageMessage`, `EmptyState`, `AppFooter` | |

### 2. バリエーション

#### 2-1. 一覧

| 切替要素 | パターン |
|---|---|
| 一覧の行 | 通常の行／固定費由来の行（「固定費」タグ付き。**この画面では編集も削除もできない**。「›」は表示しない） |
| 金額の表記 | 支出（−¥）／収入（＋¥） |
| 一覧全体 | データあり／該当なし（`EmptyState`） |

#### 2-2. 編集シート（④）

| 状態 | 内容 |
|---|---|
| 閉（通常） | 一覧のみ表示 |
| 開（編集中） | 行を押下すると、ページ下部に編集シートが表示される。押下した行の値が各入力欄に入った状態 |
| 固定費由来の行を押下 | **編集シートは開かない**。固定費の編集・削除は固定費一覧（SCR-005）から行う旨を `PageMessage` 等で案内する |

編集シート内の各入力のバリエーションは SCR-002 とほぼ同じ。

| 項目 | バリエーション |
|---|---|
| 種別（支出／収入） | **変更不可**。選択中の種別を表示するだけで、切り替えはできない（SCR-002と異なる点） |
| 金額 | 空欄または0 → 「金額を入力してください」／1〜6桁（1〜999,999）は保存可／7桁以上 → 「999,999円までで入力してください」 |
| 日付 | 必須。過去・未来を問わずどの日付でも登録可。ただし、日付を空にしては保存できない |
| カテゴリ | 必ず1つ選択。2つ以上は選択できない。未選択で保存しようとすると「カテゴリを一つ選択してください。」 |
| メモ | 任意・200文字まで |

#### 2-3. 削除確認モーダル

| 項目 | 内容 |
|---|---|
| 表示条件 | 編集シートの「削除」ボタン、または行の左スワイプからの削除操作（固定費由来の行は対象外） |
| メッセージ | 種別で出し分ける。支出：「支出を削除しますか？」／収入：「収入を削除しますか？」 |
| ボタン | 「削除」／「いいえ」 |
| 「削除」押下 | `is_delete` を **true** にして**論理削除**する。モーダルと編集シートを閉じ、一覧を再取得して反映し、ページ上部に削除メッセージを表示する |
| 「いいえ」押下 | 確認モーダルを非表示にし、収支一覧画面を表示する（削除はしない） |

#### 2-4. ページ上部のメッセージ

| 操作 | 種別 | メッセージ |
|---|---|---|
| 保存 | 支出 | 「支出を更新しました」 |
| 保存 | 収入 | 「収入を更新しました」 |
| 削除 | 支出 | 「支出を削除しました」 |
| 削除 | 収入 | 「収入を削除しました」 |

- 表示は SCR-002 と同じ `PageMessage`（5秒後に自動で消える）。

### 3. 注意点

- 行を押下するとページ下部に編集シートが表示される。**支出／収入の区分は変更できない**。区分を誤った場合は、削除して SCR-002 で登録し直す。
- 編集シートのカテゴリ候補は、その行の種別（支出用 01／収入用 02）に対応するものだけを出す。
- **固定費由来の行（「固定費」タグ付き）は、この画面では編集も削除もできない**。編集・削除する場合は、固定費一覧（SCR-005）から該当の固定費を操作する。行を押下しても編集シートは開かず、左スワイプによる削除も使えない。
- 削除は必ず確認モーダルを挟む。削除は論理削除（is_delete=true）で、物理削除はしない。
- 削除確認モーダルは `ConfirmDialog` を使い、SCR-003 専用の実装は作らない。メッセージ・ボタン文言・押下時の処理は props で渡す。
- 保存・削除の後は、一覧と月の合計を再取得して即時反映する。
- 日付を別の月に変更して保存した場合、その行は表示中の月の一覧から消える。
- 二重送信防止：保存中・削除中は「保存する」「削除」を非活性にする。
- 戻る先は SCR-001（「‹」またはフッターの「ホーム」）。
