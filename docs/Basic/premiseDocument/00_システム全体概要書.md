## 13. 制約

| 分類 | 内容 |
| --- | --- |
| 技術的制約 | 個人開発のため、サーバーは無料〜低コストのホスティング（Render、Vercel、Supabase 等）の範囲内に収める |
| 技術的制約 | 外部有料APIは極力使わない（例：郵便番号検索APIは無料枠のみ利用） |
| リソース制約 | 開発者は1名（レビュアー不在、テストも開発者自身が行う） |
| 環境制約 | 対応ブラウザは Chrome・Edge・Firefox |
| 環境制約 | スマートフォンのブラウザを優先し、表示崩れが起きないようにする |
| データ取り扱い制約 | パスワードの平文保存は禁止する |
| データ取り扱い制約 | クレジットカード番号など、決済情報そのものは保存しない |

## 14. スコープ対象外

以下は今回の開発対象外とする。ただし、ネイティブアプリ化と通知機能は二次開発で対応する。

| 対象外の機能 | 補足 | 二次開発 |
| --- | --- | --- |
| 銀行口座・クレジットカードとの自動連携 | 手入力のみ対応する | — |
| レシート画像のOCR自動読み取り | — | — |
| 家族間でのデータ共有 | 1ユーザー＝1家計簿の範囲とする | — |
| ネイティブアプリ化（iOS / Androidストア配信） | Webブラウザ利用のみとする | 対応予定 |
| 多言語対応 | 日本語のみとする | — |
| AIによる支出予測・自動カテゴリ分類 | — | — |
| 通知機能（メール・プッシュ通知） | アプリを開いたときにのみ確認できればよい | 対応予定 |
