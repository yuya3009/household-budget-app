# 家計簿アプリ 要件定義書

## 第5章 機能一覧書（一次開発）

[MVP範囲書](02_MVP範囲書.md)で定義した4機能を、実装単位まで分解した一覧。
ユーザ登録・ログイン機能はMVP対象外のため含まない。

---

### 1. 機能一覧

| 機能ID | 機能名 | 使用用途 |
|---|---|---|
| FUC-001 | 支出・収入登録機能 | 支出または収入の新規データを記録する |
| FUC-002 | 支出・収入編集機能 | 登録済みの支出・収入データの内容を修正する |
| FUC-003 | 支出・収入削除機能 | 登録済みの支出・収入データを削除する |
| FUC-004 | 支出・収入一覧表示機能 | 登録済みの支出・収入データを一覧形式で表示する |
| FUC-005 | 固定費登録機能 | 月次または年次で発生する固定費データを新規登録する |
| FUC-006 | 固定費編集機能 | 登録済みの固定費データの内容を修正する |
| FUC-007 | 固定費削除機能 | 登録済みの固定費データを削除する |
| FUC-008 | 固定費一覧表示機能 | 登録済みの固定費データを一覧形式で表示する |
| FUC-009 | 固定費自動計上機能 | 登録済みの固定費を、該当する月の支出データとして自動的に反映し、都度の入力を不要にする |
| FUC-010 | カテゴリ区分設定機能 | 支出カテゴリごとに「削減対象」「維持対象」の区分と、削減対象の優先度を設定・変更する |
| FUC-011 | 月次収支グラフ表示機能 | 月ごとの収入・支出の推移をグラフで表示する |
| FUC-012 | カテゴリ別支出グラフ表示機能 | カテゴリ別の支出内訳をグラフで表示する |
| FUC-013 | 削減対象カテゴリ内訳表示機能 | 支出削減設定で「削減対象」とした支出に絞った内訳をグラフで表示し、削減効果の大きい箇所を判断できるようにする |
| FUC-014 | 削減金額設定機能 | 削減対象としたカテゴリごとに、1か月あたりに削減してよい金額を設定する。カテゴリ単位のため、そのカテゴリの固定費・変動費の両方が対象になる |
| FUC-015 | カテゴリ登録機能 | 支出用・収入用のカテゴリを新規登録する |
| FUC-016 | カテゴリ編集機能 | 自分が作成したカテゴリの名称・アイコン・説明を修正する |
| FUC-017 | カテゴリ削除機能 | 自分が作成したカテゴリを削除する |
| FUC-018 | カテゴリ一覧表示機能 | 登録済みのカテゴリ（デフォルト＋自分が作成したもの）を支出用・収入用に分けて一覧表示する |
