# 家計簿アプリ 要件定義書

## 第3章 画面一覧書（一次開発）

[MVP範囲書](02_MVP範囲書.md)で定義した4機能を実現するために必要な画面を一覧化する。
ユーザ登録・ログイン機能はMVP対象外のため、ログイン画面等は含まない。

---

### 1. 画面一覧

| 画面ID | 画面名 | 使用用途 |
|---|---|---|
| SCR-001 | ホーム（ダッシュボード）画面 | アプリ起動時に最初に表示する画面。当月の収支と月次収支推移を確認し、メニューから収支一覧・固定費一覧・カテゴリ設定・支出削減設定へ遷移する |
| SCR-002 | 収支入力画面 | 支出または収入を新規に記録する |
| SCR-003 | 収支一覧画面 | 登録済みの支出・収入を一覧で確認し、内容の編集・削除を行う |
| SCR-004 | 固定費登録画面 | 月次または年次で発生する固定費（家賃・保険料・サブスク等）を登録する |
| SCR-005 | 固定費一覧画面 | 登録済みの固定費を一覧で確認し、内容の編集・削除を行う |
| SCR-006 | カテゴリ設定画面 | 支出用・収入用のカテゴリを一覧で確認し、追加・編集・削除を行う |
| SCR-007 | グラフ・レポート画面 | 月次収支推移やカテゴリ別内訳など、支出削減の判断材料となるグラフを詳細に確認する |
| SCR-008 | 支出削減設定画面 | 支出カテゴリごとに「削減対象」「維持対象」の区分と、削減対象の優先度を設定する |
| SCR-009 | 削減金額設定画面 | SCR-008で削減対象にしたカテゴリごとに、1か月あたりの削減金額を設定して保存する |

---

### 2. 画面-機能対応表

各画面がどの機能（[機能一覧書](05_機能一覧書.md)）を提供するかを示す。

| 画面ID | 画面名 | 関連する機能ID |
|---|---|---|
| SCR-001 | ホーム（ダッシュボード）画面 | FUC-011 |
| SCR-002 | 収支入力画面 | FUC-001 |
| SCR-003 | 収支一覧画面 | FUC-002, FUC-003, FUC-004 |
| SCR-004 | 固定費登録画面 | FUC-005 |
| SCR-005 | 固定費一覧画面 | FUC-006, FUC-007, FUC-008 |
| SCR-006 | カテゴリ設定画面 | FUC-015, FUC-016, FUC-017, FUC-018 |
| SCR-007 | グラフ・レポート画面 | FUC-011, FUC-012, FUC-013 |
| SCR-008 | 支出削減設定画面 | FUC-010 |
| SCR-009 | 削減金額設定画面 | FUC-014 |

※ FUC-009（固定費自動計上機能）は画面を持たないバックグラウンド処理のため、上表には対応する画面IDを記載していない。処理結果はSCR-001・SCR-003に反映される。
